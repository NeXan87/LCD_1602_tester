Расчёт выходного напряжения и разности сигналов с учётом делителя после ОУ

Vout_OU = (Vin+ - Vin-) × G + Vref
ΔV = (Vout_OU - Vref) / G
С учётом делителя после ОУ:
Vout_OU = Vout_ADC / Kdiv
ΔV = (Vout_ADC / Kdiv - Vref) / G
Питание ОУ: 3.3 В
Делитель после ОУ: 5.1 кОм + 10 кОм
Kdiv = Rниз / (Rверх + Rниз) = 10 / (5.1 + 10) = 0.662
Vout_ADC = Vout_OU × Kdiv

Расчёт по напряжению после делителя:
Vout_OU = Vout_ADC / Kdiv = 2.00 / 0.6667 = 3.00 В
ΔV = (Vout_OU - Vref) / G = (3.00 - 2.50) / 0.50 = 1.00 В
ℹ️ Важная информация:

• При питании 3.3 В: входной диапазон –0.3…2.1 В, выходной 0.015…3.28 В

• При питании 5.0 В: входной диапазон –0.3…3.8 В, выходной 0.015…4.98 В

• Для делителя 5.1к+10к: Kdiv = 0.662 (выход 5В → 3.31В на АЦП)

• Для делителя 5к+10к: Kdiv = 0.667 (выход 3В → 2.00В на АЦП)

• Красный цвет = выход за пределы допустимого диапазона ОУ
